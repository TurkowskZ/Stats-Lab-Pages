Explore the interplay among alpha, sample size, standardized effect size, the noncentrality parameter, and power.

Core Decision and Effect Parameters

Type I Error (α)
Rejecting H₀ when H₀ is true. Conventional alpha criteria include .05 or .01.
Type II Error (β)
Failing to reject H₀ when H₀ is false. Retaining a false baseline.
Power (1 − β)
Correct decision: rejecting H₀ when H₀ is false. Probability of detecting a true effect.
Standardized Effect Size (d)
Difference between population means scaled by standard deviation: d = (μ₁ − μ₂) / σ. In samples: d = (M − μ) / S.
Noncentrality Parameter (δ)
Combines effect size and sample size into a single metric representing the distribution shift: δ = d√n (one-sample and dependent-samples designs; for two independent groups of n each, δ = d√(n/2)).
Critical Cutoff (tcrit / zcrit)
Cuts off the rejection region on the sampling distribution under H₀ at the designated α level.
Cohen's Reference Conventions for Effect Size (d)
Verbal Description Effect Size (d) Practical Interpretation
Small ±0.2 Subtle shift; requires large sample size for adequate detection power.
Medium ±0.5 Noticeable effect typical of applied experimental manipulations.
Large ±0.8 Substantial separation between population distributions.

Lab Guided Reflection

1. Significance Criterion Variations (α)

Adjust alpha upward and downward while holding d and n constant.

What does tightening α from .05 to .01 do to the critical value cutoff, beta, and power?

Check Answers for Alpha Criterion

Decreasing α (e.g., .05 to .01): To minimize Type I error risk, the critical cutoff shifts further into the tail of H₀. This larger cutoff intersects deeper into the H₁ distribution, increasing β (Type II error) and decreasing statistical power.

Increasing α: Moves the critical threshold inward, shrinking the β region and raising power at the cost of a higher false positive risk.

2. Effect Size Variations (Cohen's d)

Adjust Cohen's d across benchmarks (0.2, 0.5, 0.8).

What does altering d do to the distance between distributions, noncentrality parameter δ, and test power?

Check Answers for Effect Size

Increasing d: Directly scales the shift between the H₀ and H₁ population means. This drives up the noncentrality parameter (δ = d√n), pushing the H₁ distribution past the critical cutoff and dramatically boosting power.

Independence of sample size: Cohen's d reflects the underlying magnitude of effect rather than sample size. A small effect with high n can achieve high statistical significance without possessing substantial clinical or practical significance.

3. Sample Size Variations (n) and the Noncentrality Shift

Adjust sample size n to observe changes in the standard error (SM) and noncentrality parameter (δ).

Why does increasing n elevate statistical power without altering true effect size d?

Check Answers for Sample Size

Mechanism: Increasing n reduces standard error (SM = S / √n), making both sampling distributions narrower. On the standardized scale, δ = d√n increases, driving the H₁ distribution further into the rejection region.

Required Sample Size for Power = 0.8: Using the lecture formula n = (δ / d)², where δpower=0.8 = 2.80 for a two-tailed test at α = .05, researchers solve directly for the necessary n (rounding up) to achieve the target level of power. For example, d = 0.50 gives n = (2.80 / 0.50)² = 31.4, so n = 32.

4. Test Directionality (One-Tailed vs. Two-Tailed)

Switch between two-tailed and one-tailed tests.

How does directionality impact critical cutoffs and power?

Check Answers for Test Directionality

One-Tailed: Allocates the full α area into a single tail, placing the critical cutoff closer to zero (e.g., 1.645 instead of 1.96 at α = .05). This lowers β and raises power for effects predicted in that specific direction.

Two-Tailed: Splits the risk (α / 2 in each tail), requiring a more extreme sample mean to reject H₀, protecting against effects in the unpredicted direction.
