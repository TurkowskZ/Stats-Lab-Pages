Why Do We Need Both Wide and Long Formats?

Repeated measures ANOVA in R requires two different data shapes depending on the function:

  • Wide Format (Lab10Wide): Every participant gets a single row (Subject 1 through 8), and every combination of repeated conditions gets its own column (Left10 through Right40). The car::Anova() function requires this wide matrix structure to model within-subjects covariance.

  • Long Format (Lab10Long): Every single observation gets its own row (\(8 \text{ subjects} \times 2 \text{ hemispheres} \times 4 \text{ time points} = 64 \text{ rows}\)), with separate factor columns for Subject, Hemisphere, and Time, plus a single outcome column for Cerebral Blood Flow Velocity (CBFV). Standard lm() models used with emmeans() require this long layout.

Note

Note on reshaping: Lab10Data.csv originally loads in a semi-long layout where subjects repeat across four time blocks. The reshape() function pivots those blocks horizontally into 8 rows and 9 columns, and column indexing reorders the variables so all Left Hemisphere columns appear together (Left10:Left40) followed by all Right Hemisphere columns (Right10:Right40).

Wide formatted data

# Load wide data
Lab10Wide = read.table("Lab10Data.csv",
                       sep = ",",

                    idvar = "Subject",

# Rename columns to match the rest of the script

Setting Orthogonal Contrasts

R defaults to treatment contrasts (contr.treatment), which compare every level against a baseline reference group and produce incorrect Type III Sums of Squares when interactions are present. Setting contr.sum forces zero-sum deviation coding so car::Anova(..., type = 3) partitions variance accurately.

# "contr.sum" is the correct option for type III SS
options(contrasts = c("contr.sum", "contr.poly"))

Reading the Omnibus Output and Sphericity Corrections

Look at the three tables printed by summary(a_one, multivariate = FALSE):

  1. Univariate Type III ANOVA (Assuming Sphericity): Shows a massive effect of Time, \(F(3, 21) = 199.06, p = 1.405 \times 10^{-15}\).

  2. Mauchly Tests for Sphericity: Tests whether the variances of the differences between all pairs of time points are equal. Here, \(W = 0.098, p = .0228\). Because \(p < .05\), sphericity is violated, meaning the uncorrected \(F\)-test is overly liberal.

  3. Greenhouse-Geisser (GG) and Huynh-Feldt (HF) Corrections: Because sphericity is violated, adjust the degrees of freedom using an epsilon (\(\epsilon\)) multiplier:

  • Greenhouse-Geisser (more conservative, preferred when \(\epsilon < .75\)): \(\epsilon = 0.4956\), yielding \(p = 1.192 \times 10^{-8}\).

  • Huynh-Feldt (less conservative): \(\epsilon = 0.5982\), yielding \(p = 4.570 \times 10^{-10}\).

Step 3: How Epsilon Corrections Work Under the Hood

The next two chunks prove mathematically why multiplying degrees of freedom by \(\epsilon\) changes the \(p\)-value without changing the \(F\)-statistic:

  • Both numerator degrees of freedom (\(df_{\text{Time}} = 3 \times 0.4956 = 1.49\)) and denominator degrees of freedom (\(df_{\text{Error}} = 21 \times 0.4956 = 10.41\)) are scaled by the exact same \(\epsilon\) constant.

  • Because \(MS = SS / df\), scaling both \(df\) terms by \(\epsilon\) cancels out when computing \(F = MS_{\text{Time}} / MS_{\text{Error}}\) (\(F\) remains \(199.063\)). However, evaluating \(F = 199.063\) against a narrower \(F(1.49, 10.41)\) reference distribution via pf() yields the corrected \(p\)-value.

# How the GG and HF corrections work.
# 1) You multiply any df in your omnibus by the epsilon value. In this case 
# your variable of interest and the error term.
df_time_GG  = 3 * 0.4956
df_error_GG = 21 * 0.4956

df_time_HF  = 3 * 0.5982211
df_error_HF = 21 * 0.5982211

# 2) Plug in the F you have and the new df to get your new p, which is already 
# printed in the summary above. Below is a fuller demonstration.

# p-values with the adjusted dfs (F = 199.063 from the omnibus)
cat(sprintf("Manually calculated p-value for GG correction: %e\n", pf(199.063, df_time_GG, df_error_GG, lower.tail = FALSE)))
Manually calculated p-value for GG correction: 1.192053e-08
cat(sprintf("Manually calculated p-value for HF correction: %e\n", pf(199.063, df_time_HF, df_error_HF, lower.tail = FALSE)))
Manually calculated p-value for HF correction: 4.570093e-10
# You don't need to recalculate your various SS or MS values, because the df
# scales all the values the same way. This means that the top and bottom of the
# fraction that gives you F have both been scaled the same way. For example, 
# if you multiply the top and bottom of 1/4 by 3, you still have 1/4.

# Full demonstration of the correction (reuses the dfs above).
SS_time  = 7774.125
SS_error = 273.375

# Greenhouse-Geisser
MS_time_GG  = SS_time  / df_time_GG
MS_error_GG = SS_error / df_error_GG
F_GG        = MS_time_GG / MS_error_GG

# Huynh-Feldt
MS_time_HF  = SS_time  / df_time_HF
MS_error_HF = SS_error / df_error_HF
F_HF        = MS_time_HF / MS_error_HF

Step 4: Partial Eta Squared (\(\eta_p^2\))

Using the Sums of Squares from the ANOVA table (\(SS_{\text{Time}} = 7774.125\), \(SS_{\text{Error}} = 273.375\)), manual partial eta squared is computed as:

\[\eta_p^2 = \frac{SS_{\text{Time}}}{SS_{\text{Time}} + SS_{\text{Error}}} = \frac{7774.125}{7774.125 + 273.375} = 0.966\]

This matches the eta_squared(a_one) output of \(0.97\) (\(95\% \text{ CI } [0.94, 1.00]\)).

# Calculate partial eta-squared for Time using SS values from the omnibus table
partialEta_Time = 7774.125 / (7774.125 + 273.375)

Step 5: Post Hoc Pairwise Comparisons (No Need for Simple Effects)

Because the omnibus one-way test for Time is significant, follow up with pairwise comparisons across all four time points. Subset Lab10Long to "Left" and fit lm(CBFV ~ Time + Subject, data = Lab10OneWayLong). Step 2: Interpreting the Two-Way Omnibus Table

From summary(a, multivariate = FALSE), examine all three effects:

  • Main Effect of Hemisphere: \(F(1, 7) = 138.16, p = 7.305 \times 10^{-6}\). (No sphericity test is needed because Hemisphere only has 2 levels.)

  • Main Effect of Time: \(F(3, 21) = 519.05, p < 2.2 \times 10^{-16}\). Mauchly’s test is significant (\(p = .0450\)), so apply Greenhouse-Geisser (\(\epsilon = 0.5848, p = 2.214 \times 10^{-12}\)).

  • Hemisphere \(\times\) Time Interaction: \(F(3, 21) = 11.25, p = .00013\). Mauchly’s test is significant (\(p = .0055\)), so apply Greenhouse-Geisser (\(\epsilon = 0.5147, p = .00345\)).

5. Sample APA 7 Results Write-Up

The following is a complete APA 7th edition write-up for the two-way repeated measures ANOVA. Because over-reporting is encouraged for this lab to ensure you capture every statistical component, this example reports the sphericity diagnostics, Greenhouse-Geisser corrected omnibus tests, partial eta squared values, both sets of simple effects, and all pairwise post hoc comparisons alongside cell means and standard deviations (using Tukey-adjusted \(p\)-values from the emmeans output).

TipResults

A 2 (Hemisphere: Left, Right) \(\times\) 4 (Time: 10, 20, 30, 40) within-subjects repeated measures analysis of variance (ANOVA) was conducted to examine changes in cerebral blood flow velocity (CBFV) across time and between hemispheres (\(N = 8\)). Mauchly’s test indicated that the assumption of sphericity was violated for the main effect of Time, \(W = 0.133, p = .045\), and for the Hemisphere \(\times\) Time interaction, \(W = 0.053, p = .006\); therefore, degrees of freedom were corrected using Greenhouse-Geisser estimates of sphericity (\(\epsilon = 0.585\) for Time and \(\epsilon = 0.515\) for the interaction).

Omnibus Effects

There was a statistically significant main effect of Hemisphere, \(F(1, 7) = 138.16, p < .001, \eta_p^2 = .95\), with overall CBFV being significantly higher in the left hemisphere than in the right hemisphere (\(M_{\text{diff}} = 9.12, SE = 0.98\)), \(t(49) = 9.35, p < .001\). There was also a significant main effect of Time, \(F(1.75, 12.28) = 519.05, p < .001, \eta_p^2 = .99\) (uncorrected \(df = 3, 21\)). Marginal pairwise comparisons using Tukey’s HSD indicated that CBFV decreased significantly across every consecutive time interval averaged across hemispheres: from Time 10 to Time 20 (\(M_{\text{diff}} = 26.31, SE = 1.38\)), \(t(49) = 19.06, p < .001\); Time 10 to Time 30 (\(M_{\text{diff}} = 40.81, SE = 1.38\)), \(t(49) = 29.56, p < .001\); Time 10 to Time 40 (\(M_{\text{diff}} = 48.88, SE = 1.38\)), \(t(49) = 35.40, p < .001\); Time 20 to Time 30 (\(M_{\text{diff}} = 14.50, SE = 1.38\)), \(t(49) = 10.50, p < .001\); Time 20 to Time 40 (\(M_{\text{diff}} = 22.56, SE = 1.38\)), \(t(49) = 16.34, p < .001\); and Time 30 to Time 40 (\(M_{\text{diff}} = 8.06, SE = 1.38\)), \(t(49) = 5.84, p < .001\).

Crucially, these main effects were qualified by a statistically significant Hemisphere \(\times\) Time interaction, \(F(1.54, 10.81) = 11.25, p = .003, \eta_p^2 = .62\) (uncorrected \(df = 3, 21\); multivariate \(\eta_p^2 = .90\)). To decompose this interaction, simple effects and pairwise follow-up comparisons were conducted in both directions.

Simple Effects of Hemisphere at Each Level of Time

Because Hemisphere had only two levels, pairwise comparisons were conducted directly at each time point. At Time 10, there was no significant difference in CBFV between the left hemisphere (\(M = 113.38, SD = 6.63\)) and the right hemisphere (\(M = 113.62, SD = 6.55\)), \(t(49) = -0.13, p = .899\). However, CBFV was significantly higher in the left hemisphere than in the right hemisphere at Time 20 (\(M_{\text{Left}} = 90.88, SD = 4.22\) vs. \(M_{\text{Right}} = 83.50, SD = 5.63\)), \(t(49) = 3.78, p < .001\); at Time 30 (\(M_{\text{Left}} = 80.25, SD = 2.96\) vs. \(M_{\text{Right}} = 65.12, SD = 3.31\)), \(t(49) = 7.75, p < .001\); and at Time 40 (\(M_{\text{Left}} = 71.75, SD = 4.37\) vs. \(M_{\text{Right}} = 57.50, SD = 3.59\)), \(t(49) = 7.30, p < .001\).

Simple Effects of Time at Each Level of Hemisphere

Because Time had four levels, one-way repeated measures ANOVAs were first conducted separately for each hemisphere. For the left hemisphere, Mauchly’s test indicated a violation of sphericity, \(W = 0.098, p = .023\) (\(\epsilon_{\text{GG}} = 0.496\)), and there was a significant simple main effect of Time, \(F(1.49, 10.41) = 199.06, p < .001, \eta_p^2 = .97\) (uncorrected \(df = 3, 21\)). Tukey-adjusted pairwise comparisons within the left hemisphere revealed significant decreases in CBFV between all time points: Time 10 (\(M = 113.38, SD = 6.63\)) was significantly higher than Time 20 (\(M = 90.88, SD = 4.22\)), \(t(49) = 11.52, p < .001\), Time 30 (\(M = 80.25, SD = 2.96\)), \(t(49) = 16.97, p < .001\), and Time 40 (\(M = 71.75, SD = 4.37\)), \(t(49) = 21.32, p < .001\); Time 20 was significantly higher than Time 30, \(t(49) = 5.44, p < .001\), and Time 40, \(t(49) = 9.80, p < .001\); and Time 30 was significantly higher than Time 40, \(t(49) = 4.35, p < .001\).

For the right hemisphere, Mauchly’s test also indicated a violation of sphericity, \(W = 0.043, p = .003\) (\(\epsilon_{\text{GG}} = 0.596\)), and there was a significant simple main effect of Time, \(F(1.79, 12.51) = 257.75, p < .001\) (uncorrected \(df = 3, 21\)). Tukey-adjusted pairwise comparisons within the right hemisphere likewise showed significant decreases in CBFV across all intervals, with steeper overall reductions than in the left hemisphere: Time 10 (\(M = 113.62, SD = 6.55\)) was significantly higher than Time 20 (\(M = 83.50, SD = 5.63\)), \(t(49) = 15.43, p < .001\), Time 30 (\(M = 65.12, SD = 3.31\)), \(t(49) = 24.84, p < .001\), and Time 40 (\(M = 57.50, SD = 3.59\)), \(t(49) = 28.74, p < .001\); Time 20 was significantly higher than Time 30, \(t(49) = 9.41, p < .001\), and Time 40, \(t(49) = 13.32, p < .001\); and Time 30 was significantly higher than Time 40, \(t(49) = 3.91, p = .002\).

Quick Checklist for Students Writing Their Own Results

When adapting this template for homework or exams, verify these four items:

  1. Corrected Degrees of Freedom: Whenever Mauchly’s test has \(p < .05\), multiply both \(df_{\text{effect}}\) and \(df_{\text{error}}\) by \(\epsilon_{\text{GG}}\) (e.g., \(3 \times 0.5147 = 1.54\) and \(21 \times 0.5147 = 10.81\)) and report the corrected \(p\)-value (Pr(>F[GG])).

  2. Matching Means and SDs: Pull \(M\) and \(SD\) directly from describe(Lab10Wide[2:9]) so every cell mentioned in your pairwise comparisons has its descriptive statistics attached.

  3. One-Way Simple Effect Prerequisite: Always state the one-way RM ANOVA \(F\)-test for factors with 3 or more levels (Time at Left; Time at Right) before reporting the pairwise \(t\)-tests for that factor.

  4. Consistency in Correction Method: Pick one post hoc adjustment family (Tukey, Bonferroni, or Scheffé) and stick with its exact \(p\)-values throughout the write-up rather than mixing and matching across paragraphs.
